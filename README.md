Each component carries its own CSS and JS, so a page ships only what it uses. A project adds one Eleventy plugin and maps its own data to the layout props.

| Package | Holds |
| --- | --- |
| [`@allons-y/webc-patterns`](packages/webc-patterns#readme) | The components, the `norn-*` layouts, and the Norn plugin |
| [`@allons-y/webc-code-sample`](packages/webc-code-sample#readme) | A code sample component with build-time highlighting |
| [`@allons-y/webc-studio`](packages/webc-studio#readme) | The Allons-y Studio theme |

Each package README covers setup and options. The [component preview](https://allonsy-studio.github.io/webc-resources/) shows every component and layout.

## Development

Node 22 or later.

```sh
yarn install
yarn lint
yarn test
```

See [AGENTS.md](AGENTS.md) for conventions and the release flow.
