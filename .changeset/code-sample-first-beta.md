First beta: `norn-code-block`, a WebC code sample highlighted at build time. Prism runs during the build, and the browser gets token ranges for the CSS Custom Highlight API and a compact `norn-copy-button` over the code's top end corner, with no highlighter shipped. The code has no border. A frame with a flat header bar for the caption is there for a page that sets `--norn-chrome: terminal`. Its names and copy button texts are named slots, falling back to `componentStrings`, then English, and the code is a named tab stop only while it scrolls. It is an optional peer of `@allons-y/webc-patterns`: installed, the Norn plugin registers the component, `tokenRanges` as `nornTokenRanges`, and the Markdown add-on, and the Norn layouts show their samples with it. Theme it with the shared tokens, such as `--norn-code-keyword`, set in a project `tokens.css`. Exports `codeBlock`, `tokenRanges`, and `loadLanguages`. The Markdown add-on is `@allons-y/webc-code-sample/markdown`: `highlightFences` renders fenced code as the `norn-code-block` an author would write, with no strings of its own.
