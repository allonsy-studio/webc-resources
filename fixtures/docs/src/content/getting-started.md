---
title: Getting started
description: Install the project and run it once.
order: 1
---
Install the package:

```sh
$ npm install @allons-y/fixture-docs
```

Then run it once with `npx`.

> [!TIP]
> The first run caches its results, so the next one is faster.

> [!WARNING]
>
> Node 22 or later is required.
