# Table

| Option | Type | Default | What it does |
| --- | --- | --- | --- |
| `reportDeprecations` | `boolean` | `false` | Logs a warning for every deprecated option a project still passes, with the name of the option and the one that replaces it. |
| `strictSlots` | `boolean` | `true` | Fails the build when a page fills a slot a component does not have. |
| `iconSet` | `string` | `"default"` | Names the icon set the components draw from when a page does not pass its own. |
