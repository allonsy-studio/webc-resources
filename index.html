Components

Norn is a set of WebC components and layouts for Eleventy. This preview renders each one from its package, with its examples, props, slots, and custom properties.

The packages hold no components yet, so there is nothing to show; each one appears here as it lands.

Packages

Each component ships in one of three packages.

  • @allons-y/webc-patterns 0.1.0-beta.0: Generic WebC page and docs patterns for Eleventy sites: head, header, footer, hero, card, side nav, docs shell, and pager.
  • @allons-y/webc-code-sample 0.1.0-beta.0: WebC code sample component with build-time syntax highlighting and no highlighter shipped to the browser.
  • @allons-y/webc-oss-site 0.1.0-beta.0: Allons-y Studio open source project site layer: studio banner, call to action, footer credit, page bodies, and site data builders.
