norn-rich-text

Prose styles for long-form content: headings, paragraphs, lists, quotes, tables, rules, and inline code, all at one line height. A heading that links to itself is a norn-heading-anchor, which styles its own # and takes the same space above as a plain heading. Wrap the content in it: <norn-rich-text><template webc:nokeep @html="content"></template></norn-rich-text>. Rules in tables and dividers and the quote bar take --norn-ui-border-color, and inline code --norn-surface-code.

<norn-rich-text> a container, from @allons-y/webc-patterns

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@measure string Line length: text, --norn-text-measure, or none, the full width, as in a page whose prose holds to the measure child by child. Falls back to text.

NameDescription
default The prose, as rendered HTML.
