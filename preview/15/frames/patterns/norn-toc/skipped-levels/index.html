Getting started

An overview of the project and what it does.

Install the project, then run it once to see it work. The steps below take a few minutes on a new machine.

Set up the project folder before the first build.

The package needs Node 24 or later. Check the version with node --version first.

Design tokens set the colors, the type, and the spacing.

Override a token in the project's own stylesheet, and every component follows it.

Import the package and call it with a name.

It returns the greeting as a string, and keeps no state between calls.
