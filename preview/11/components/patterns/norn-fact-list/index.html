norn-fact-list

Short facts in a row, such as a license or a runtime: an optional icon and a few words each, with no box. Static text, not controls. Pass each fact as an <li>, which may start with a norn-icon. The list has role="list", which Safari needs once the markers are gone.

<norn-fact-list> a component, from @allons-y/webc-patterns

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@gap string The space between rows: xs, s, m, or l, each a --norn-space-* step. The facts in a row are always m apart. A hero sets l. Falls back to xs.

Slots

NameDescription
default The facts, as <li> elements.
