Components

Norn is a set of un-opinionated WebC components and helpers for Eleventy. Every component in the three packages is rendered here by Eleventy from the packages themselves. Pick one for its examples, props, slots, and custom properties.

Layout

Arranges other things: page frames.

  • norn-sidebar-layout

    A navigation column beside the page body.

Landmark

A page region with a role and a name: header, navigation, footer.

  • norn-breadcrumbs

    Where the page sits in the site: a trail of links from the top down, ending at the current page, marked with aria-current="page".

  • norn-footer

    Site footer: a row of columns, and a colophon below them.

  • norn-header

    Site header: the brand link, then the primary navigation.

  • norn-pager

    Links to the pages before and after this one.

  • norn-side-nav

    Sidebar navigation from a list of pages.

  • norn-toc

    The page's contents: a link to each section heading, as an outline.

Container

A bounded surface that holds content: a card, a card grid, a section, a hero.

  • norn-accordion

    A stack of disclosures, from native <details> elements: the browser handles the keyboard, find-in-page, and links into a closed section.

  • norn-callout

    An aside in long-form text, set apart like a pull quote: a short label with an icon over the body, on a quiet raised panel.

  • norn-card

    A card: a heading, then its text, on a raised surface.

  • norn-card-grid

    Responsive grid of cards.

  • norn-code-tabs

    The same thing in a few forms, such as npm, yarn, and pnpm, as tabs over norn-code-blocks.

  • norn-hero

    Page intro, in the default slot: an h1, a lede, the actions, the facts, and anything after, such as an install norn-code-block.

  • norn-notice

    A message about the page or the site: information, success, a warning, or an error, with an icon and an optional action.

  • norn-rich-text

    Prose styles for long-form content: headings, paragraphs, lists, quotes, tables, rules, and inline code, all at one line height.

  • norn-simple-table

    A native table that scrolls sideways inside its own box when it is wider than the page, so the page never does.

Component

A self-contained element: a link, a code block, a lockup.

  • norn-code-block

    Code sample tokenized at build time.

  • norn-copy-button

    A button that copies text to the clipboard: @value, or the text of the element whose id is @source.

  • norn-fact-list

    Short facts in a row, such as a license or a runtime: an optional icon and a few words each, with no box.

  • norn-heading-anchor

    A heading that links to itself, so a reader can copy a link to the section.

  • norn-icon

    Inline SVG icon from a small built-in set or the project's own, drawn in currentColor at 1em.

  • norn-link-button

    A link styled as a button, for a call to action.

  • norn-search

    Site search: a search landmark with a field that lists results as the visitor types, from a Pagefind index.

  • norn-segmented-control

    A row of mutually exclusive options drawn as one control, from native radio buttons in a fieldset.

  • norn-skip-link

    Link that jumps past the page chrome to the main content.

  • norn-theme-toggle

    Light, system, or dark: a norn-segmented-control that sets the page's color-scheme and remembers the choice in localStorage under color-scheme.

Template

An Eleventy layout: a whole page, filled from props.

  • norn-base

    The page frame every Norn layout extends: the head, the skip link, norn-header, main, and norn-footer, filled from props.

  • norn-docs

    A docs page: the sticky docs sidebar with site search above its list, the page title, its contents when it has two or more sections, the body in norn-rich-text, and the pager.

  • norn-docs-home

    A docs site's home page: the hero with the install sample, then the docs pages as a contents list, each title and then its description.

  • norn-landing

    A project's landing page: the hero with the usage or install sample, then the install, features, and packages sections.

  • norn-workspace

    One workspace's page in the docs frame: the workspaces sidebar, its name, its description, and its page, such as its SKILL.md or README.md rendered to HTML.

  • norn-workspaces-home

    A monorepo's home page: the hero with the install sample, then an index of the workspaces, titles in the mono face.

Document

The head and the foundation styles, with no body markup.

  • norn-head

    Head metadata, the cascade layer order, and the page's bundle links.

OSS site

The OSS site theme: its bar, call to action, credit, and head, from one package.

  • oss-bar

    OSS banner, shown before the page's header.

  • oss-credit

    OSS credit lockup for the footer, light or dark by the scheme the page uses.

  • oss-cta

    OSS call to action, at the foot of the page.

  • oss-head

    The OSS site head: the PT Mono preload and the self-hosted @font-face rules for PT Mono, Instrument Sans, and Yellowtail, each with a fallback matched to its metrics.

Packages

Each component ships in one of three packages.

  • @allons-y/webc-patterns 0.1.0-beta.3: Generic WebC components and Eleventy layouts for page and docs sites, with the Norn plugin that registers them: header, footer, hero, cards, side nav, docs shell, and pager.
  • @allons-y/webc-code-sample 0.1.0-beta.3: WebC code sample component with build-time syntax highlighting and no highlighter shipped to the browser.
  • @allons-y/webc-oss-site 0.1.0-beta.3: The OSS site theme for Norn sites: Allons-y Studio brand tokens, self-hosted fonts, and the locked OSS banner, call to action, and footer credit.
