Theme

The shared tokens in tokens.json. Each component reads a token as the custom property with its default as the fallback, so nothing defines them until a project does. Every one carries the --norn- prefix, so it can sit next to a project's own custom properties, and its name is the path joined with hyphens: ui.border.color is --norn-ui-border-color. Set any of them in unlayered CSS to restyle every component.

Change a token in the Override column to try it. A color has a light and a dark value, each from its own picker. Any other token takes any CSS value, such as 1.5rem. Overrides are saved in this browser and apply to every preview page, in this tab and in any other that is open.
