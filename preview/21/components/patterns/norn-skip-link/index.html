norn-skip-link

Link that jumps past the page chrome to the main content. Hidden until it has focus: press Tab from the top of the page to show it. Give the target tabindex="-1", as in <main id="main" tabindex="-1">.

<norn-skip-link> a component, from @allons-y/webc-patterns

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@href string The target's fragment. Falls back to #main.

Slots

NameDescription
label The link text, as one element, such as <span slot="label">Aller au contenu</span>. Falls back to the site's componentStrings, then "Skip to content".
