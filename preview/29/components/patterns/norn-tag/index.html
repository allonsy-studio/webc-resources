norn-tag

A topic label. With @href it is a link: a hairline edge at control contrast, a state layer and an underline on hover and focus, and a heavier edge and label when it is the current page or an active filter. Without @href it is a static tint with no edge, and not focusable. Inside norn-tag-filter, a tag with @tag becomes a toggle.

<norn-tag> a component, from @allons-y/webc-patterns

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@href string Where the tag links, such as the tag's page. With it the tag is a link with the edge of a control; without it, a static label.
@color string A tint from a shared color token: accent, or a status color. Without it the tint is the text color. The label stays in the text color, so the word carries the meaning. One of accent, info, success, warning, or danger.
@current boolean Mark the tag of the page the visitor is on, with aria-current="true". Only on a tag with href.
@tag string The key norn-tag-filter matches against each item's data-tags, such as css. Only on a tag with href.

Slots

NameDescription
default The label, in sentence case.

Tokens

The global tokens from tokens.json the component reads. Set one in a project's tokens.css to change it everywhere.

Type a value to try it in every example above. Reset puts the default back.
