Getting started

Install the project, then run it once to see it work. The steps below take a few minutes on a new machine.

Install

The package needs Node 24 or later. Check the version with node --version first.

With npm

Run npm install --save-dev @example/core in the project folder. npm writes the version to the lockfile.

Pinned versions

Pass an exact version, such as @example/core@1.2.0, to install that release and no other.

Version ranges

A range lets npm pick the newest release that fits, each time the lockfile is updated.

Caret ranges

A caret range, such as ^1.2.0, accepts any 1.x release from 1.2.0 up.

npm writes a caret range by default when it adds a package.
