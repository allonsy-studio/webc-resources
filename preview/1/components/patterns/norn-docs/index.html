norn-docs

A docs page: the sticky docs sidebar with site search above its list, the page title, its contents when it has two or more sections, the body in norn-rich-text, and the pager. Extends norn-base. When the page is 60rem wide or more, the contents are a sticky column at the end of the body. Narrower, they fold under their title, and the sidebar folds into a closed <details> under the sidebar's name. The search is live from a Pagefind index at pagefind/, or a web search of the site's host without one. Only the page body is indexed. The contents list comes from nornHeadings over the body: headingAnchors, which the plugin adds to Markdown, writes the anchored headings. The sidebar's name ("Documentation") and the search label ("Search the docs") come from componentStrings under norn-docs, then English.

layout: norn-docs.webc a template, from @allons-y/webc-patterns

Props

The plugin's props mapping sets them on each page, and the layout reads them as $data.norn.

NameTypeDescription
docs { url: string, title: string, icon?: string }[] The docs pages, in order. icon names a sidebar norn-icon.
prev { url: string, title: string } Falls back to the page before this one in docs, by nornAdjacent.
next { url: string, title: string } Falls back to the page after this one in docs.
search { bundle?: string, site?: string } | false Pagefind's script (falls back to /pagefind/pagefind.js) and the host the plain form searches (falls back to the host of url). false leaves the search out.
