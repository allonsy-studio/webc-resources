norn-callout

An aside within prose: a note, tip, important point, warning, or caution, with an icon and a title, and the body in the default slot. The kinds match GitHub's alerts. callouts in @allons-y/webc-patterns/markdown writes the same markup for a Markdown > [!NOTE] blockquote. Its role is note: it is not a landmark.

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@variant string note, tip, important, warning, or caution. Falls back to note.

Slots

NameDescription
heading The title, as one element, such as <span slot="heading">Careful</span>. Falls back to the site's componentStrings for the variant, then the variant's name, such as "Note".
default The body.

Custom properties

Type a value to try it in every example above. Reset puts the default back.

Property Type Default Override
--norn-ui-accentThe brand color, shared by every component. <color> #2346d4
--norn-callout-colorThe bar, icon, and title color. <color> a status color per variant, and to --norn-text-accent for `important`
--norn-callout-bgBackground. none a tint of the color
