norn-callout

An aside in long-form text, set apart like a pull quote: a short label with an icon over the body, on a quiet raised panel. Use it for a fun fact, a tip, or a point worth a pause. It is not a status message: use norn-notice for one. The kinds match GitHub's alerts and differ only in the label's color, its default text, and its icon. callouts in @allons-y/webc-patterns/markdown writes the same markup for a Markdown > [!NOTE] blockquote. Its role is note: it is not a landmark.

<norn-callout> a container, from @allons-y/webc-patterns

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@variant string The kind of aside. One of note, tip, important, warning, or caution. Falls back to note.

Slots

NameDescription
heading The label over the body, as one element, such as <span slot="heading">Did you know?</span>. Falls back to the site's componentStrings for the variant, then the variant's name, such as "Note".
default The body.
