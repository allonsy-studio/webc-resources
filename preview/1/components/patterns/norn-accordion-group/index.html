norn-accordion-group

A stack of disclosures, from native <details> elements: the browser handles the keyboard, find-in-page, and links into a closed section. Pass each section as a <details> with a <summary> in the default slot. Give them one name to keep only one open at a time. A section slides open where the browser can animate to an intrinsic size, unless motion is reduced; elsewhere it opens at once.

<norn-accordion-group> a container, from @allons-y/webc-patterns
