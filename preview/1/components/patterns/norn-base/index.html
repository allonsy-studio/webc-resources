norn-base

The page frame every Norn layout extends: the head, the skip link, norn-header, main, and norn-footer, filled from props. The Norn plugin ships it as an Eleventy layout; use it as layout: norn-base.webc for a WebC page, or extend it from a layout of the project's own. A page that uses it directly and is not a WebC file, such as Markdown, has its content compiled, so the components the Markdown add-ons write render. Content that is already compiled (a WebC page, or a page on a layout that extends it) is inserted as it is, because compiling it again would render its kept component tags twice. It tells them apart by the page's own layout and page.inputPath, which a layout chain leaves alone. Props are $data.norn: the plugin's props mapping, or the same-named page data. Every list defaults to []. The head calls norn-page-head, which declares the cascade layer order first, then embeds the base and print styles: the plugin fills the two style blocks below from css/base.css and css/print.css. A copy of this file pastes their text in. Four hooks take markup from fillHooks: head at the end of the head, banner before the header, cta at the end of main, and credit as the footer's last column. The footer's texts ("Licensed under {license}", the navigation's name "Footer") come from componentStrings under norn-base, then English.

layout: norn-base.webc a template, from @allons-y/webc-patterns

Props

The plugin's props mapping sets them on each page, and the layout reads them as $data.norn.

NameTypeDescription
lang string The page language. Falls back to page.lang, then en.
dir "ltr" | "rtl" | "auto" The text direction, set on <html>. Without it, rtl for a right-to-left language (ar, fa, he, ur, ps, yi, dv, ckb, sd, ug, matched on the primary subtag of lang), else ltr.
title string The page title. The document title is the title and the name; a page without one shows the name and the tagline.
name string The site name: the brand link, the footer lead, og:site_name.
tagline string A short line after the name.
description string
url string The canonical URL.
ogTitle string Falls back to the document title.
ogImage { src: string, alt?: string } The share image, or its URL: og:image, og:image:alt, and twitter:card (summary_large_image). A relative src resolves against url, which must then be absolute: with no absolute url, the build logs a norn-page-head: warning and og:image and og:image:alt are left out. Without an image, no image tag renders. Either way the card is summary.
locale string og:locale, such as en_US.
themeColor string One color for both schemes. Without it, the page surface in each scheme.
themeToggle boolean Apply the scheme a norn-theme-toggle saved, before the first paint.
icon { href: string, type?: string } The favicon, or its URL. Without it the page links an empty icon, so browsers skip /favicon.ico.
touchIcon string A 180px PNG for home screens.
logo { src: string, alt?: string } The brand image, or its URL, in place of the name. The brand link renders only with a logo or a name.
nav { url: string, title: string, icon?: string }[] The header links. icon names a norn-svg-icon.
footer { name?: string, text?: string, license?: { name: string, url: string }, badges?: { href: string, src: string, alt: string, width?: number, height?: number }[], groups?: { heading: string, links: { url: string, title: string }[] }[], colophon?: string } The footer: the lead column (name falls back to the site name, text to the tagline), its badges and license, one navigation of grouped links, and a closing line.
