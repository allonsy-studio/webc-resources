norn-page-toc

The page's contents: a link to each section heading, as an outline. Each heading sits in a nested list under the nearest heading above it with a lower level, so an h3 is listed inside the h2 it belongs to and a skipped level adds no empty list. The input stays flat. Data-driven, from headings (registered as nornHeadings), so it stays in step with the page. Its script marks the section in view with aria-current="location". With fewer than two headings it renders nothing.

<norn-page-toc> a landmark, from @allons-y/webc-patterns
