norn-sidebar-layout

A navigation column beside the page body. Layout only: it sets no heading style and no line length. A page that uses it directly styles its own h1 and sets --norn-rich-text-measure, as norn-docs and norn-workspace do. Wrap prose in norn-rich-text. Pass the navigation as one element in the nav slot, such as <norn-side-nav slot="nav" …>, and the body, starting with its h1, in the default slot. The navigation stays in view while the page scrolls, and a long list scrolls inside it. When the frame is narrower than 37.5rem the columns stack, and the navigation folds into a closed <details> above the body, under the summary text. A browser without ::details-content always shows the fold. Sections and articles inside the body stack with a small gap.

<norn-sidebar-layout> a layout, from @allons-y/webc-patterns

Slots

NameDescription
nav The navigation, as one element.
summary The text of the control that opens the navigation on a narrow frame, as one element. Falls back to the site's componentStrings, then "Menu". A layout passes the navigation's own name.
default The page body, starting with its h1.

Custom properties

Type a value to try it in every example above. Reset puts the default back.

Property Type Default Override
--norn-ui-accentThe brand color, shared by every component. <color> #2346d4
--norn-sidebar-layout-navNavigation column width. <length> 14rem
--norn-sidebar-layout-widthOverall width. <length> --norn-layout-width 64rem
--norn-sidebar-layout-gapSpace between the navigation and the body. <length> --norn-space-l 2rem
--norn-sidebar-layout-columnsThe body's grid columns. none one column. A page sets it on the body's `article` to put something beside its prose, as `norn-docs` does with its contents
