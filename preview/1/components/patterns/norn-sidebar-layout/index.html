norn-sidebar-layout

A navigation column beside the page body. Layout only: it sets no heading style and no line length. A page that uses it directly styles its own h1 and sets --norn-rich-text-measure, as norn-docs and norn-workspace do. Wrap prose in norn-rich-text. Pass the navigation as one element in the nav slot, such as <norn-side-nav slot="nav" …>, and the body, starting with its h1, in the default slot. The navigation stays in view while the page scrolls, and a long list scrolls inside it. The columns stack, and the navigation scrolls with the page, when the frame is narrower than 37.5rem. Sections and articles inside the body stack with a small gap.

<norn-sidebar-layout> a layout, from @allons-y/webc-patterns
