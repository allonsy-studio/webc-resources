norn-link-button

A link styled as a button, for a call to action. It navigates, so it stays a link: use a <button> for an action on the page. The default slot is the link text, and may hold a norn-icon. A hover and a press take a layer of the text color over the background, and the text is never underlined.

<norn-link-button> a component, from @allons-y/webc-patterns

Props

NameTypeDescription
@href required string
@variant string primary, a filled accent; secondary, a 1px outline; or quiet, text with no border. Falls back to primary.
