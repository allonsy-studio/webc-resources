norn-hero

Page intro, in the default slot: an h1, a lede, the actions, the facts, and anything after, such as an install norn-code-block. Write the h1 as one or two <span>s: the name, then a tagline in the accent color. The actions are a <nav aria-labelledby="…">, pointing at a hidden name, holding a <ul role="list"> of norn-link-buttons, and the facts a norn-fact-list with @gap="l".

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@width string Content width: layout, --norn-layout-width, or measure, the prose line length, --norn-text-measure. Falls back to layout.

Slots

NameDescription
default The h1, lede, actions, facts, and extras, in that order.

Tokens

The global tokens from tokens.json the component reads. Set one in a project's tokens.css to change it everywhere.

Type a value to try it in every example above. Reset puts the default back.
