norn-hero

Page intro, in the default slot: an h1, a lede, the actions, the facts, and anything after, such as an install norn-code-block. Write the h1 as one or two <span>s: the name, then a tagline in the accent color. The actions are a <nav aria-labelledby="…">, pointing at a hidden name, holding a <ul role="list"> of norn-link-buttons, and the facts a norn-fact-list. Sets --norn-chrome: terminal so a code sample inside takes the window-bar frame.
