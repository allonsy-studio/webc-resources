norn-breadcrumb-nav

Where the page sits in the site: a trail of links from the top down, ending at the current page, marked with aria-current="page". Data-driven, so the last item is always the current one. The separators are decorative chevrons that point the reading way, so they mirror in right-to-left text.

<norn-breadcrumb-nav> a landmark, from @allons-y/webc-patterns
