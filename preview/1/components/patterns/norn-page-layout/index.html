norn-page-layout

Docs page frame: a navigation column beside the page body. Layout only: wrap prose in norn-rich-text. Pass the navigation as one element in the nav slot, such as <norn-side-nav slot="nav" …>, and the body, starting with its h1, in the default slot. The navigation stays in view while the page scrolls, and a long list scrolls inside it. The columns stack, and the navigation scrolls with the page, when the frame is narrower than 37.5rem. Sections and articles inside the body stack with a small gap.

<norn-page-layout> a layout, from @allons-y/webc-patterns
