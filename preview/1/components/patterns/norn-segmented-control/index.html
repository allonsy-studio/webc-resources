norn-segmented-control

A row of mutually exclusive options drawn as one control, from native radio buttons in a fieldset. No script: the browser handles the keyboard and the form value. Each option is a <label> holding an <input type="radio">, an optional norn-icon, and its text in a <span>. Give the radios one name, and the labels a title when the text is hidden. The checked option is tinted in the accent, and the others take a hover and a press layer. Options are drawn at equal widths. A component that builds one from its own props passes @legend, @name, and :@options instead, since its props don't reach slot content.

<norn-segmented-control> a component, from @allons-y/webc-patterns

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@icon-only boolean Hides the option text visually; it stays the radio's name. On for @icon-only, @icon-only="true", or :@icon-only="true".
@legend string The group's name, when the legend slot is empty.
@name string The radios' shared name. Required with options: the build fails without it.
@options { value: string, label: string, icon?: string, checked?: boolean }[] The options, in place of the default slot. Each label is also its title.

Slots

NameDescription
legend The group's name, as one element, such as <span slot="legend">Color scheme</span>. Visually hidden.
default The option labels, when there are no options.
