norn-side-nav

Sidebar navigation from a list of pages. Marks the current page with aria-current="page", and a page holding it with aria-current="true". An item may carry a norn-icon name and child pages, which list under it, indented. The current page takes a tint of the accent and the accent as its text color, and the pointer takes a lighter layer. In a sticky norn-sidebar-layout column only the list scrolls, so a search field in the search slot stays put.

<norn-side-nav> a landmark, from @allons-y/webc-patterns
