norn-page-pager

Links to the pages before and after this one. Renders nothing when both are missing. Get the pages from adjacent, registered as nornAdjacent, at the call site. The arrows are drawn in CSS, not read, and point the other way in right-to-left text.

<norn-page-pager> a landmark, from @allons-y/webc-patterns

Slots

NameDescription

Custom properties

Type a value to try it in every example above. Reset puts the default back.

Property Type Default Override
--norn-ui-accentThe brand color, shared by every component. <color> #2346d4
--norn-page-pager-borderRule above the links. <color> --norn-ui-border-color light-dark(#d3d8e2, #2d323e)
--norn-page-pager-linkLink color. <color> --norn-text-accent light-dark(oklch(from color-mix(in oklch, var(--norn-ui-accent, #2346d4) 82%, black) min(l, 0.5) c h), oklch(from color-mix(in oklch, var(--norn-ui-accent, #2346d4) 55%, white) max(l, 0.72) c h))
