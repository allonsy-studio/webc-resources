norn-copy-button

A button that copies text to the clipboard: @value, or the text of the element whose id is @source. It stays hidden without a script or where the Clipboard API is missing, so it never offers what it can't do. After a click its label reads the copied or failed text for two seconds, and a status message says the same to a screen reader. The texts are in the page, hidden, and the script shows them: the button only exists with a script.

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@value string The text to copy.
@source string The id of the element whose text to copy, when there is no value.
@strings string The id of an element that holds the texts in place of the slots, for a component that wraps the button, as norn-code-block does. It holds one element per slot, marked data-string="label", "copy", "copied", and "failed"; the label one needs an id.

Slots

NameDescription
label The button's accessible name, such as "Copy the install command", as one element. Without it, the visible text names the button.
copy The visible text, as one element. Falls back to the site's componentStrings, then "Copy".
copied The text after a copy. Falls back to the site's componentStrings, then "Copied".
failed The text when the copy fails. Falls back to the site's componentStrings, then "Copy failed".
