norn-data-table

A native table that scrolls sideways inside its own box when it is wider than the page, so the page never does. Pass the <table> in the default slot, with a <caption> when it can have one. Cells and code in them wrap between words, never mid-word. Its script makes the box a named, focusable region only while it scrolls, so a keyboard can scroll it. scrollTables in @allons-y/webc-patterns/markdown writes the same markup for Markdown tables.
