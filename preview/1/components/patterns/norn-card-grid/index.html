norn-card-grid

Responsive grid of cards. Each card takes the next accent color. Pass each card in an <li>, as in <li><norn-content-card>…</norn-content-card></li>. The list has role="list", which Safari needs once the markers are gone. Each card spans three rows of the grid, with grid-template-rows: subgrid, so the headings, the bodies, and the footers of cards in a row line up. A browser without subgrid shows each card as its own box.

<norn-card-grid> a container, from @allons-y/webc-patterns

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@mono boolean Set the card titles in the mono face. On for @mono, @mono="true", or :@mono="true".

Slots

NameDescription
default The cards, each in an <li>.

Custom properties

Type a value to try it in every example above. Reset puts the default back.
