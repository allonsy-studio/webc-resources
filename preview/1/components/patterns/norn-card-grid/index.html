norn-card-grid

Responsive grid of cards. Pass each card in an <li>, as in <li><norn-card>…</norn-card></li>. The list has role="list", which Safari needs once the markers are gone. Each card spans three rows of the grid, with grid-template-rows: subgrid, so the headings, the bodies, and the footers of cards in a row line up. A browser without subgrid shows each card as its own box.

<norn-card-grid> a container, from @allons-y/webc-patterns
