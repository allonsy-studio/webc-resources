norn-card-grid

Responsive grid of cards. Pass each card in an <li>, as in <li><norn-card>…</norn-card></li>. The list has role="list", which Safari needs once the markers are gone. Each card spans three rows of the grid, with grid-template-rows: subgrid, so the headings, the bodies, and the footers of cards in a row line up. A browser without subgrid shows each card as its own box. Settings for a card, such as its title face or its top line, go on the card as props: <norn-card @title-face="mono">.

<norn-card-grid> a container, from @allons-y/webc-patterns

Props

Write them with the @ prefix, and :@ for an expression.

NameTypeDescription
@min string Narrowest card, as a CSS length, such as 12rem. Falls back to 17rem.
@gap string Space between cards: s, m, or l, for --norn-space-s, -m, or -l. Falls back to m.

Slots

NameDescription
default The cards, each in an <li>.
